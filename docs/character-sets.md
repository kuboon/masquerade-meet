# キャラクターセットを配布する

自分のサイトでキャラクターセットを公開すると、そのページの「このキャラセットでマスカレードする」ボタンから、あなたのキャラクターで会議を開けるようになります。masq 側への登録や申請はありません。

## 先に道具

|                                                                            |                                                                                                                |
| -------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| [`https://masq.kbn.one/character-set`](https://masq.kbn.one/character-set) | URL を入れると中身を確認でき、自分の声を録音して各キャラクターの声で聴けます。インストール不要                 |
| `deno run -A jsr:@kuboon/masquerade-character-set/cli ./set.json`          | 公開前に手元で確認。CI にも置けます                                                                            |
| `@kuboon/masquerade-character-set`（JSR）                                  | 型（root export）、チェッカ（`/check`）、声のプレビュー（`/preview`）。masq 本体もこれを同じ名前で読んでいます |

**ルームが読み込みに失敗しても、リンクを踏んだ人には何も表示されません。** 標準のキャラクターで開くだけです。気づけるのは上のどれかを使ったときだけなので、公開前に必ず通してください。

## しくみ

1. あなたのサイトに、キャラクターの一覧を書いた JSON を置く
2. `https://masq.kbn.one/new?set=<その URL>` へのリンクを置く
3. 押した人のルームがそのキャラクターで開く

ルームは**最初の接続のときに一度だけ**その URL を取りに行き、返ってきた内容を自分のストレージに固定します。あとから来た人は固定されたコピーを見るので、

- 会議の途中であなたのサイトが落ちても、その会議は最後まで動きます
- 会議の途中で JSON を書き換えても、動いている会議の顔ぶれは変わりません
- 後から来た人が URL の `?set=` を書き換えても、そのルームの顔ぶれは変わりません

読み込めなかったときはルームは標準のキャラクターで開き、ロビーに理由が出ます。会議が開けなくなることはありません。

## JSON の形

```json
{
	"name": "サーカス団",
	"tagline": "天幕の下に集まった、はぐれ者の一座",
	"banner": "banner.webp",
	"characters": [
		{
			"id": "lion",
			"name": "ライオン",
			"emoji": "🦁",
			"tagline": "ごろごろ重低音",
			"image": "lion.png",
			"voice": {
				"size": -0.95,
				"weight": -0.6,
				"nasal": -0.05,
				"roughness": 0.2
			}
		}
	]
}
```

| フィールド             | 必須 | 内容                                                  |
| ---------------------- | ---- | ----------------------------------------------------- |
| `name`                 | ○    | セットの名前（40文字まで）                            |
| `tagline`              |      | 一行の説明（60文字まで）                              |
| `banner`               |      | セットの横長画像。省略すると最初のキャラクターの絵    |
| `characters`           | ○    | 2〜40 件                                              |
| `characters[].id`      | ○    | 英数字・`-`・`_` のみ、32文字まで。セット内で重複不可 |
| `characters[].name`    | ○    | 画面に出る名前（24文字まで）                          |
| `characters[].emoji`   |      | 名前の前に付く絵文字。省略すると 🎭                   |
| `characters[].tagline` |      | 一行の説明（40文字まで）                              |
| `characters[].image`   | ○    | 絵の URL。JSON からの相対パスも書けます               |
| `characters[].voice`   | ○    | 下記                                                  |

**キャラクターの人数がそのままルームの定員です。** 15 人で会議したいなら 15 体必要です。

### 画像

`https://` のみです。JSON と同じ場所に置くなら `"lion.png"` のような相対パスで書けます。`data:` URI は使えません（セット全体が大きくなりすぎるため）。

絵は参加者のブラウザがあなたのサイトから直接読み込みます。つまり**あなたのサーバーには参加者のアクセスが記録されます**。ロビーにもその旨が表示されます。

### 声

5 つの軸で、それぞれ 0 が「変えない」、±1 が振り切りです。

|             | 範囲     | 意味                                                                 |
| ----------- | -------- | -------------------------------------------------------------------- |
| `size`      | −1 〜 +1 | 体の大きさ。−1 で 1 オクターブ下（大きい体）、+1 で 1 オクターブ上   |
| `weight`    | −1 〜 +1 | 声の重心。−1 で暗く太く、+1 で細く明るく                             |
| `nasal`     | −1 〜 +1 | −1 で箱の中のように、+1 で鼻にかかった声                             |
| `roughness` | 0 〜 1   | しゃがれ具合                                                         |
| `throat`    | −1 〜 +1 | 声の高さに対する口の大きさのちぐはぐさ。人間には出せない声になります |

`size` と `weight` / `nasal` は独立です。`size` を動かさずに `weight` や `nasal` だけ動かしても、**変装にはなりません**。

### 変装になっていない声は受け付けません

各キャラクターの声は、次のどれかを満たす必要があります。ひとつでも満たさないキャラクターがあると、**セット全体が拒否されます**。

- `size` が ±0.17 以上（2半音以上）
- `throat` が ±0.25 以上
- `roughness` が 0.3 以上

このアプリは「参加者の地声は誰にも届かない」ことが唯一の約束です。全部 0 のセットを配ると、参加者は変装しているつもりで地声を流すことになり、しかも本人はそれに気づけません。だから警告ではなく拒否です。

## HTML に埋め込む

JSON ファイルを別に置かず、ページ自体に埋め込んでも構いません。その場合はページの URL をそのまま渡します。

```html
<script type="application/masquerade-character-set+json">
	{ "name": "サーカス団", "characters": [ ... ] }
</script>

<a href="https://masq.kbn.one/new?set=https%3A%2F%2Fexample.com%2Fcircus%2F">
	このキャラセットでマスカレードする
</a>
```

`?set=` の値は URL エンコードしてください。

## 制限

|                    |       |
| ------------------ | ----- |
| JSON / ページ全体  | 64 KB |
| 取得のタイムアウト | 5 秒  |
| キャラクター数     | 2〜40 |

64 KB は本文だけの上限です。絵は別 URL なので、この中には入りません。

## 声を決める

数字を読んで声は想像できません。`https://masq.kbn.one/character-set?url=<あなたの URL>` で自分の声を5秒録音すると、各キャラクターの声で聴けます。ここで詰めてください。

コツは2つだけです。

- **誰もゼロ付近に置かない。** 自分と同じ体格の声は、変装になりません。
- **隣と離す。** `size` が 0.1 しか違わない2体は誰にも区別できません。15体なら −0.95 〜 +0.95 に 0.13 刻みくらいで並べ、そこから `weight` / `nasal` / `roughness` / `throat` で色を付けます。

`throat` は人間には出せない声（大きな体の声が小さな口から出る、など）になるので、人間でないキャラクターに向いています。
